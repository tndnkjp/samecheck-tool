# SameCheck - 重複データ抽出・ハイライトマクロ

1つのCSVファイルの中から、全列が完全に一致する「重複行」を自動で見つけ出すExcel VBAツールです。
「同じデータが二重に入力されていないか確認したい」「台帳やリストの重複チェックを毎回手作業でやっている」といった作業の自動化を想定しています。

## ダウンロード

**[⬇️ SameCheck.xlsm をダウンロード](https://github.com/tndnkjp/samecheck-tool/raw/main/SameCheck.xlsm)**

上のリンクをクリックするだけで、ブラウザが自動的にファイルをダウンロードします（gitの知識は不要です）。

## できること

- 1つのCSVファイルを選択するだけで重複チェックを実行
- 全列が完全に一致する行だけを「重複」と判定
- 重複している行を`データ`シート上で自動的に色付け（ハイライト）
- 重複している内容・件数を`重複一覧`シートにまとめて表示
- ワンクリックで`データ`・`重複一覧`シートを削除してリセット

## 使い方

1. **[`SameCheck.xlsm` をダウンロード](https://github.com/tndnkjp/samecheck-tool/raw/main/SameCheck.xlsm)して開く**
2. 黄色いセキュリティバーが出たら「コンテンツの有効化」をクリック
   （出ない場合は下記FAQ参照）
3. 「**重複をチェックする**」ボタンをクリック
4. ファイル選択ダイアログで、チェックしたいCSVファイルを指定
5. 完了すると `データ` シートに全件が表示され、重複している行には色が付く。重複の詳細は `重複一覧` シートで確認できる

結果をリセットしたい場合は、「**結果シート削除**」ボタンを押してください。

これだけで使えます。VBAエディタを開く必要はありません。

## つまずきやすいポイント（FAQ）

### 「セキュリティの警告」「マクロが無効にされました」と出る

Excelの初期設定では、インターネット経由で取得したファイルのマクロは既定でブロックされます。

- ファイルを右クリック → `プロパティ` → 下部の「許可する」にチェック → OK
- それでも警告が出る場合：`ファイル` → `オプション` → `セキュリティセンター` → `セキュリティセンターの設定` → `マクロの設定` で「警告を表示してすべてのマクロを無効にする」になっているか確認し、実行時に「コンテンツの有効化」を選択

### 一部しか違わないデータが重複として検出されない

本ツールは「すべての列が完全に一致する行」だけを重複と判定します。1文字でも違う場合（表記ゆれ、空白の有無、全角半角の違いなど）は重複として検出されません。あらかじめ表記を揃えてからチェックすることをおすすめします。

### Excelのバージョンによって動作が違う

`ADODB.Stream` と `FileDialog` を使用しており、Windows版Excel 2010以降であれば基本的に動作します。Mac版Excelは `ADODB.Stream` が利用できないため非対応です。

## カスタマイズしたい場合

既定の設定を変えたい方向けに、VBAソースコードを `src/modSameCheck.bas` として同梱しています。

1. `SameCheck.xlsm` を開き `Alt + F11` でVBEを開く
2. 左側のプロジェクトエクスプローラーで既存の `modSameCheck` を右クリック →「解放」で削除
3. `ファイル` → `ファイルのインポート` から `src/modSameCheck.bas` を選び直す
4. 冒頭の「設定セクション」の定数を書き換えて保存

| 定数 | 内容 |
|---|---|
| `INPUT_ENCODING` | 読み込むCSVの文字コード |
| `HAS_HEADER` | 1行目をヘッダーとして扱うか |
| `DELIMITER` | 区切り文字（タブ区切りなら `vbTab`） |
| `DATA_SHEET_NAME` | 元データを書き出すシート名 |
| `DUPLICATE_SHEET_NAME` | 重複一覧を書き出すシート名 |
| `HIGHLIGHT_COLOR` | 重複行のハイライト色 |

> `src/modSameCheck.bas` はShift-JIS(CP932)で保存されています。テキストエディタで直接編集する場合、UTF-8で上書き保存すると、VBEへの再インポート時に日本語コメントが文字化けするのでご注意ください。

### トラブルシューティング：文字化けする／意図した重複が検出されない

`データ` シートの文字が読めない記号になっている場合、ほとんどはCSVの文字コードと `INPUT_ENCODING` の設定が合っていないことが原因です。上記の手順で `src/modSameCheck.bas` を開き、冒頭の設定セクションにある `INPUT_ENCODING` を変更してください。

```vba
Private Const INPUT_ENCODING As String = "shift-jis"  ' 日本語の古いシステム由来のCSVに多い
Private Const INPUT_ENCODING As String = "utf-8"       ' 最近のWebサービスからのエクスポートに多い
```

迷ったら、対象CSVをメモ帳で開き、「名前を付けて保存」画面の右下に表示される文字コードを確認するのが確実です。

文字コードが合っているのに重複が検出されない場合は、上記FAQの「一部しか違わないデータが重複として検出されない」もあわせてご確認ください。

## 動作確認用サンプル
